What exists today

The browser and native editors share an editable project format. Current implementations cover timeline operations, compositions, native text and shapes, motion, color nodes, audio processing, captions and export. Tests and builds exercise these paths, but full interface and release acceptance are still underway.

Assistant edits use project operations with normal undo. Codex subscription editing has passed real project changes. Claude sign-in works; successful edits also depend on the account's remaining provider usage. No provider subscription comes with Arya.

What a useful public repository needs

A public project needs more than a visibility switch. The release should include setup instructions, reproducible tests, license notices, contribution guidance, a security contact, public-safe sample projects and a clear record of supported workflows.

We will not publish private project media, personal account settings, credentials or client designs. The publication review must include repository history, not only the latest files.

Choose it for the actual workflow

Arya does not yet match every feature of the professional editors it borrows from. Figma imports turn some layer types into rendered images. Reference look matching uses overall color statistics and needs creative review. Provider usage limits still apply. Longer real projects and physical hardware need further acceptance.
