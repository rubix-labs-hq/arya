This website

The site has no analytics, advertising scripts, account creation or email collection. It self-hosts its fonts. The website and hosted browser editor use Vercel. Vercel receives ordinary web requests, including network and browser information, and may retain request logs under its own policies. Loading the editor downloads application code; it does not by itself upload your project media.

The beta access form on the download page is a placeholder. It does not send or store what you type. When it is connected, this guide will name the service that receives it.

Contributions are not open, and this site takes no payments.

Hosted browser editor

The hosted edition keeps project records in IndexedDB and imported media and rendered outputs in the browser's origin-private file system. These belong to the current browser profile and site address. Another browser, private window or site address does not share them. Browser storage is not a backup: clearing site data, deleting a profile, storage eviction or ending a private session can remove your work.

Save a complete .arya backup with its media before clearing storage or leaving a temporary session. Wait for the download to finish and keep the file outside browser-managed temporary storage. A completed export is a rendered video or audio file, not an editable project backup. Restore the .arya backup through the browser editor; it is not a native Mac project document.

The hosted beta does not provide assistant connections, Figma sign-in, transcription or local-server analysis services. Browser export depends on available codecs and currently supports export ranges up to five minutes. The connected local-server edition and native apps have different capabilities.

Local projects and media

The editor stores the project and generated media in the folder you choose. The connected browser edition uses a local server on your computer. This is separate from the hosted browser edition described above. The native app can edit and export without the Node server. Exporting or importing a design does not by itself require sending your whole media folder to an assistant.

Connected assistants are external providers

Prompts and relevant project context go to your selected assistant provider. Context can include selected layer properties, titles, transcript text or rendered material requested by the assistant. Treat these as disclosures to that provider. Review its account and data settings.

The paired Mac companion uses official CLI sign-in and does not read or copy that CLI's stored credentials. Optional API keys use the device Keychain. Mobile companions need an explicit HTTPS connection.

Figma imports

Imports read selected design data and may fetch associated assets from Figma. Imported layers and source references become part of your local project. Public account sign-in depends on a confidential hosted OAuth broker that is not deployed yet.

Transcription and processing

The connected local-server browser edition supports local whisper.cpp when it is installed. The hosted browser edition does not run transcription. Native transcription uses Apple Speech where supported. Availability and on-device recognition depend on the platform and language. Check the permission flow before transcribing sensitive recordings.

Assistants can use transcript text for passage selection after you connect them. A locally generated transcript does not mean subsequent assistant requests stay local.

What this guide does not promise

This describes the current implementation and the selected website host. It is not a promise that all editing stays offline, that providers retain no data or that every operating-system service runs on device. The final public release will need a dated privacy policy with the selected hosting, payment and support providers.
