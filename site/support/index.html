A note from the person building Arya.

I'm building Arya to solve problems I kept seeing in creative software. I want to describe an edit, get a project with real layers, and keep working by hand whenever I want.

This takes time. There are tools to build, rough edges to fix, machines to test and updates to maintain. I want more people to be able to make good work, regardless of their budget.

If you can help, a contribution supports that work. The amount you choose should fit your circumstances.

This is a one-time contribution, not an Arya subscription. It does not include an AI provider subscription, credits, priority service or a promise about release dates.
