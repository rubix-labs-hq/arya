Only install Arya from its official release link. Verify its version and SHA-256 checksum before installing. Do not disable macOS security protections to open an unverified copy.

In your browser

The hosted browser editor at /editor/ runs in current Chrome and Edge with no install. It covers timeline editing, color grading, motion and audio, and stores projects in your browser profile. It does not include the AI assistant, Figma import or transcription; those require the Mac app or the local browser editor run from source. Read the privacy policy before you rely on browser storage, and export .arya backups of projects you care about.

What you will need

  • A Mac running macOS 14 or later (Apple silicon or Intel) with free storage for your original footage, preview media and exports.
  • An AI account (Claude Code or Codex) only if you want assistant editing. The provider's official sign-in and plan decide what you can use.
  • A Figma account only for Figma imports. Use a personal access token until public Figma sign-in is set up.
