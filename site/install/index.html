Before installing

Check the download page first. Only a reviewed, signed and notarized release will get an official download link. Signing checks and a local build are not the same as a finished public release.

The installation flow

  1. Get the official release

    Check the version, system requirements and checksum on the download page. Updates currently use manual replacement in Applications.

  2. Install and open Arya

    Open the disk image, quit any running Arya instance, drag Arya to Applications and wait for Finder to finish. Eject the image, open Arya from Applications and check its version in Finder's Get Info. Follow the instructions packaged with that release. Accept a macOS permission prompt only when its app name and requested action match what you are doing. Do not bypass a security warning.

  3. Choose a project folder

    Keep the project file, imported media and generated outputs together. Start with copies of valuable footage while you learn the workflow. Keep a separate backup before major edits.

  4. Edit by hand or connect an assistant

    Import footage and use the timeline, or open Settings to connect a supported account. Assistant editing remains optional.

  5. Review your first edit

    Inspect the clips, titles, audio and layers. Check the change receipt and use Undo when you need to. Preview the marked export range before delivery.

Updates and rollback

Before updating, save projects and finish or stop assistant runs. Back up complete project folders with their media, and keep the previous approved installer and its published checksum. If Arya's companion is running in Terminal, press Control-C in that companion's window and wait for it to exit. Quit Arya before replacing its Applications copy. Keep any retained Reel.app closed. Start the companion again from the installed app's Assistant settings if needed.

To return to a previous version, save work, stop the companion if running and quit Arya. Verify the previous approved installer's checksum against its release page, replace the Applications copy, eject the image and check the installed version. Open a separate copy of the backup made before the update. A project saved by a newer app may not open in an older version. Replacing the app does not undo project edits or convert the project to an older format. Keep preferences, account connections and folder permissions in place. Stop and use support if macOS blocks the app.

Connect your assistant

On Mac, Claude Code is the suggested default. Settings can open its official CLI sign-in. Codex can use supported ChatGPT sign-in through the same paired companion. Complete the provider flow, then refresh status in Arya.

Signing in does not guarantee remaining usage. The provider decides eligible plans, models and limits. Arya does not read or copy the provider's credentials. An API key is an optional alternative where supported.

iPad and iPhone cannot run desktop CLIs locally. Their assistant workflow needs an explicitly configured HTTPS companion. Antigravity is not offered as a built-in editor connection because its current permission setup cannot be isolated per editing run.

When something goes wrong

macOS warns about the app

Stop and verify the release source and checksum. Do not remove quarantine attributes or disable Gatekeeper. Public distribution must pass notarization first.

My assistant says it is signed in but cannot edit

Check that the provider is selected, its CLI is installed, the companion is connected and your plan has usage available. Refresh status after finishing the provider sign-in.

I moved footage and now it is missing

Restore the project folder and media layout from your backup. Keep original media available and do not delete it merely because a preview proxy exists.

I cannot find an installer or payment receipt

Check the download page for current availability. This website does not process a payment or generate a receipt. A configured payment provider must provide its own confirmation and support.
