Before installing

Download Arya from the download page. The Mac disk image is signed with a Developer ID certificate and notarized by Apple. Check the version, system requirements (macOS 14 or later) and SHA-256 checksum on the download page before installing.

The installation flow

  1. Download the official release

    Download the notarized DMG from the download page and check its version and SHA-256 checksum. Updates use manual replacement in Applications.

  2. Open the DMG and drag Arya to Applications

    Open the downloaded disk image, quit any running Arya instance, drag Arya to Applications and wait for Finder to finish copying. Eject the disk image and open Arya from Applications. On first launch, macOS Gatekeeper shows a standard prompt asking to confirm opening an app downloaded from the internet. Check that the prompt names Arya and click Open. You can confirm the version at any time in Finder's Get Info window.

  3. Choose a project folder

    Keep the project file, imported media and generated outputs together in a dedicated local folder. Keep a separate backup of your original footage before major edits.

  4. Edit by hand or connect an assistant

    Import footage and use the timeline right away, or open Settings to connect Claude Code or Codex. Assistant editing is optional.

  5. Review your first edit

    Inspect the clips, titles, audio and layers. Check the change receipt and use Undo when you need to. Preview the marked export range before delivery.

Updates and rollback

Before updating, save projects and finish or stop assistant runs. Back up complete project folders with their media, and keep the previous installer and its published checksum. If Arya's companion is running in Terminal, press Control-C in that companion's window and wait for it to exit. Quit Arya before replacing its Applications copy. Start the companion again from the installed app's Assistant settings if needed.

To return to a previous version, save work, stop the companion if running and quit Arya. Verify the previous installer's checksum against its release page, replace the Applications copy, eject the image and check the installed version in Get Info. Open a separate copy of the backup made before the update. A project saved by a newer app may not open in an older version. Replacing the app does not undo project edits or convert the project to an older format. Keep preferences, account connections and folder permissions in place.

Connect your assistant

On Mac, Claude Code is the suggested default. Settings can open its official CLI sign-in. Codex can use supported ChatGPT sign-in through the same paired companion. Complete the provider flow, then refresh status in Arya.

Signing in does not guarantee remaining usage. The provider decides eligible plans, models and limits. Arya does not read or copy the provider's credentials. An API key stored in the macOS Keychain is an optional alternative where supported.

The hosted browser editor at /editor/ does not include assistant connections. Assistant editing requires the Mac app or the local browser editor run from source.

When something goes wrong

macOS warns about the app

On first launch, macOS shows a standard Gatekeeper prompt for apps downloaded from the internet. Confirm that it names Arya and click Open. If macOS warns that the app is damaged or cannot be verified, stop and check the download URL and SHA-256 checksum on the download page. Do not disable Gatekeeper.

My assistant says it is signed in but cannot edit

Check that the provider is selected, its CLI is installed, the companion is connected and your plan has usage available. Refresh status after finishing the provider sign-in.

I moved footage and now it is missing

Restore the project folder and media layout from your backup. Keep original media available and do not delete it merely because a preview proxy exists.

How do I update?

Download the new DMG from the download page or GitHub Releases, verify its SHA-256 checksum, quit Arya and drag the new app into Applications to replace the previous copy.
