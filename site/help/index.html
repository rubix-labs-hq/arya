Arya Help

Import, playback, saving and export help for Arya on Mac, iPhone and iPad.

On this pageImport mediaPlayback problemsSave and back upExportGet help

Import media

On iPhone and iPad, add media from Files or Photos. On Mac, use Import Media or drag files into Arya. Keep the original files available until importing finishes. Cloud-only files may need to download first.

If a file is missing, open it in your device’s video player and try importing it into a new project. Record its file type, codec and any error message for your report.

Playback problems

  • Blank viewer. Move the playhead over a clip and check that its track is visible.
  • Frozen playback. Save the project, reopen it and try again.

Save and back up

Native apps. Back up the project folder and its media together.

Browser editor. Export a .arya backup before clearing site data, switching browsers or changing domains.

Export your work

Open Deliver, choose a format and destination, and check the available space. Wait for export to finish before closing Arya or moving the file. On iPhone and iPad, keep Arya active if the device cannot export in the background.

Get help or report a problem

Open the Arya issue tracker and include the steps to reproduce the problem, the Arya version, and your device or operating system. Remove private media, account details and access tokens from attachments.
