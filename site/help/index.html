Import, playback, saving and export help for Arya on Mac, iPhone and iPad.

On this pageImport mediaPlaybackSave and back upExportGet help

Import media

On iPhone and iPad, add media from Files or Photos. On Mac, use Import Media or drag files into Arya. Keep the original files available until importing finishes. Cloud-only files may need to download first.

If a file does not appear, try opening it in the system video player and importing it into a new project. Record the file type, codec and any error message when reporting the issue. You do not need to share private footage.

Check playback

Confirm that the playhead is over a clip and that its track is visible. If playback stops updating, save your project, reopen it and retry. Include your device, operating system and Arya version in a report so we can reproduce it.

Save and back up

Native projects stay in the project folder you choose. Keep that folder and its media together when moving or backing up a project. The browser editor stores work in the current browser profile. Export a .arya backup before clearing website data or moving to a different browser or domain.

Export your work

Use Deliver to choose an output format and destination. Wait for the completed export before closing Arya or moving the output file. On iPhone and iPad, keep Arya active if your device does not support background export. Check that the destination has enough free space.

Get help or report a problem

Open the Arya issue tracker with the steps to reproduce the problem, the Arya version and your device or operating system. Remove private media, account details and access tokens from anything you attach.
